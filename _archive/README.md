# Αρχείο σελίδων υπηρεσιών (εκτός ιστότοπου)

Σελίδες υπηρεσιών που βγήκαν από τον ιστότοπο στις 26/09/2026 (μόνο υπηρεσίες οχημάτων).
Φάκελοι που ξεκινούν με «_» δεν δημοσιεύονται από το GitHub Pages.

Επαναφορά: μετακίνηση του φακέλου πίσω στη ρίζα (και του en/…), αφαίρεση του `noindex`,
`hidden: true` → αφαίρεση στο config.js, προσθήκη στο sitemap.xml, στο μενού και στο υποσέλιδο.
